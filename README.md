# Documentos MIC

Archivos Markdown del inventario de herramientas MIC.

- Descarga directa: `https://github.com/OWNER/REPO/releases/download/docs/<archivo>`
- Ver como texto: `https://raw.githubusercontent.com/OWNER/REPO/main/docs/<archivo>`

Los archivos están en `docs/` y se llaman `<herramienta>.<es|en>.md`. Hay además `full-report` (completo) y `general-report`.
Cada vez que cambian los `.md`, un workflow los valida, los publica y comprueba que cualquiera puede descargarlos. No edites nada a mano en la release.
